## Base theme
**Human Magic theme**, restyled.

- **Structure is reusable; styling is not**

## Implications
- Page templates, modules, and form components come from HubSpot/Human Magic
- All visual identity (color, type, spacing, motion) must be custom-styled on top
- Opportunities listing must use a HubSpot-native dynamic content pattern (HubDB or blog) so non-developers can add entries — see [[site-map]]
- Forms are HubSpot forms with routing for the two intent paths — see [[site-map]]

**Why:** HubSpot Starter + Human Magic was chosen to keep cost low and let Mark/team self-serve content updates. We don't have license to swap stacks.
**How to apply:** When designing, verify the layout is achievable in HubSpot modules before promising it. Don't design something that requires a custom front-end framework.
